# Moksha Desktop receipts for SliTaz GNU/Linux

This repository contains `receipt` files to build (cook) Moksha Desktop packages for SliTaz GNU/Linux.

These receipts were written from scratch using the template generated by the `cook new` command,
as described in the [SliTaz Handbook](https://doc.slitaz.org/handbook/build.html).
